\problem{Problem 1}
We have an economy with the following characteristics:\\\\
\begin{itemize}
    \item Two classes: Workers and Capitalists.
    \item Both classes have a constant propensity to save.
    \item Labor and capital markets are perfectly competitive.
    \item Workers' income sources are wages and profits, while capitalists' income source is only profits.
    \item The economy operates in discrete time.
    \item There is a single good produced.
    \item Workers save differently from labor and capital income.
    \item The production function uses CES with the form of:\\
    $$f(k) = (\alpha + (1 - \alpha)k^{\rho})^{\frac{1}{\rho}}$$
\end{itemize}
Where:
\begin{itemize}
    \item $k$ represents the total capital (sum of capital owned by workers, $k_w$, and capitalists, $k_c$).
    \item $s_{ww}$ represents workers' saving out of wages.
    \item $s_{wp}$ represents workers' saving out of capital's revenue.
    \item $s_c$ represents capitalists' savings.
    \item We assume $s_c > \max{s_{ww}, s_{wp}}$.
\end{itemize}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\partof{a}
$$G(k_w, k_c) = \left(\frac{s_{ww}f(k) - k f'(k)}{s + \delta}, \frac{s_c f'(k) k_c}{s + \delta}\right)$$
