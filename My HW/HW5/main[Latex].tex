\problem{Problem 1}
The constant-relative-risk-aversion utility function is
\begin{align*}
    u(C_t) = \frac{C_t^{1-\theta}}{1-\theta}
\end{align*}
From solving Romer's model we had:
\begin{align*}
    \frac{\dot{C_t}}{C_t} = \frac{r_t - \rho}{\theta} \imp r_t = \rho + \theta \frac{\dot{C_t}}{C_t}
\end{align*}
Since all consumers are identical, the equilibrium consumption would be: $C_t \bar{L}=Y_t$.
Taking derivative we will see that the growth rate of output and consuption are equal, so substituting the growth rate, $BL_A \frac{1-\phi}{\phi}$, we get:
\begin{align*}
    r = \rho + \theta BL_A \frac{1-\phi}{\phi}
\end{align*}
From solving the model in the book, we've had calculated the present value of profit, now substituting the last equation into it, we get:
\begin{align*}
    \pi_t = \dfrac{\dfrac{1-\phi}{\phi} (\bar{L} - L_A) \dfrac{w_t}{A_t}}{\rho + \theta BL_A \dfrac{1-\phi}{\phi} - BL_A \dfrac{1-2\phi}{\phi}}
\end{align*}
In the equilibrium present value of profit is equal to cost of invention,$\dfrac{w_t}{BA_t}$, so solving the equilibrium condition we have:
\begin{align*}
    \frac{w_t}{BA_t} &= \dfrac{\dfrac{1-\phi}{\phi} (\bar{L} - L_A) \dfrac{w_t}{A_t}}{\rho + \theta BL_A \dfrac{1-\phi}{\phi} - BL_A \dfrac{1-2\phi}{\phi}}                                                              \\
    \implies \frac{1}{B} &= \dfrac{\dfrac{1-\phi}{\phi} (\bar{L} - L_A) }{\rho + BL_A \biggl[\theta \dfrac{1-\phi}{\phi} - \dfrac{1-2\phi}{\phi}\biggr]}                                                                          \\
    \implies \bar{L} - L_A &= \frac{\phi}{1-\phi}
    \frac{\rho + BL_A \biggl[\theta \dfrac{1-\phi}{\phi} - \dfrac{1-2\phi}{\phi}\biggr]}{B}                                                                                                                             \\
    \implies \bar{L} - L_A &= \frac{\phi}{1-\phi}
    \frac{\rho}{B}
    L_A \biggl[\theta \dfrac{1-\phi}{\phi} - \dfrac{1-2\phi}{\phi}\biggr]
\end{align*}
Which can be simplified and solved for $L_A$ as
\begin{align*}
    \bar{L} - L_A &= \frac{\phi}{1-\phi} \frac{\rho}{B} +
    \frac{\phi}{1-\phi} L_A \frac{1}{\phi} (\theta(1-\phi) - (1-2\phi)) \\
    \implies \bar{L} - \frac{\phi}{1-\phi} \frac{\rho}{B} &=
    \frac{\phi}{1-\phi} L_A \left(\frac{1}{\phi} (\theta(1-\phi) - (1-2\phi))\right) + L_A\\
    \implies \bar{L} - \frac{\phi}{1-\phi} \frac{\rho}{B} &=
    L_A (\frac{\phi}{1-\phi} \left(\frac{1}{\phi} (\theta(1-\phi) - (1-2\phi))\right) + 1)\\
    \implies \bar{L} - \frac{\phi}{1-\phi} \frac{\rho}{B} &=
    L_A (\theta - \frac{1-2\phi}{1-\phi} + 1)\\
    \implies L_A &= \frac{1}{\phi + \theta - \phi \theta}  \biggl((1-\phi)\bar{L} - \frac{\phi \rho}{B}\biggr)\;\checkmark
\end{align*}\\
So the optimal level of cunsomption would be:
$$L_A = \max\bigl\{\frac{1}{\phi + \theta - \phi \theta}  \biggl((1-\phi)\bar{L} - \frac{\phi \rho}{B}\biggr),\;0\bigr\}$$

\problem{Problem 2}
\partof{a}
The patent price is given as: $$\frac{\delta w_t}{\phi} - w_t.$$\\
So the innovater's profit can be calculated by putting the new profit in the patent holder's profit equation:
\begin{align*}
    \pi_t & = \frac{\bar{L} - L_A}{A_t} \biggl[\frac{\delta w_t}{\phi} - w_t\biggr] \\
          & = \frac{\bar{L} - L_A}{A_t} w_t\biggl[\frac{\delta - \phi}{\phi}\biggr]
\end{align*}
From the main model, we can plugin the interest rate and profit's growth rate, so we get:
\begin{align*}
    \pi_t &= \dfrac{\biggl(\dfrac{\delta - \phi}{\phi}\biggr)\dfrac{\bar{L} - L_A}{A_t} w_t}
    {\rho + BL_A \dfrac{1-\phi}{\phi} - \dfrac{1-2\phi}{\phi} BL_A}\\
    &= \frac{\delta - \phi}{\phi} \frac{\bar{L} - L_A}{\rho + BL_A}\frac{w_t}{A_t}
\end{align*}
In the equilibrium cost and present value of profit are equal, so we have
\begin{align*}
    \frac{w_t}{BA_t} = \frac{\delta - \phi}{\phi} \frac{\bar{L} - L_A}{\rho + BL_A}\frac{w_t}{A_t}
\end{align*}\\\\
Solving the equilibrium equation for $L_A$, we get:
\begin{align*}
    \bar{L}-L_A&=\dfrac{1}{B}\frac{\phi}{\sigma-\phi}(\rho+BL_A)\\
    \implies L_A &= \frac{\delta - \phi}{\delta} \bar{L} - \frac{\phi}{\delta} \frac{\rho}{B}
\end{align*}
We have the growth rate as $\dfrac{1-\phi}{\phi}(BL_A)$. Substituting $L_A$, we get:
\begin{align*}
    \frac{\dot{Y}_t}{Y_t} = B\bar{L} \frac{\delta - \phi}{\delta} \frac{1-\phi}{\phi} - \frac{1-\phi}{\delta}\rho 
\end{align*}
Taking derivative, We have:
\begin{align*}
    \rond{\dot{Y}_t/Y_t}{\delta} &= \frac{1-\phi}{\phi} B\bar{L} \biggl(\frac{\delta - (\delta - \phi)}{\delta^2}\biggr) + \frac{1-\phi}{\delta^2} \rho \\
    &= \frac{\phi}{\delta^2} \frac{1-\phi}{\phi} B\bar{L} + \frac{1-\phi}{\delta^2} \rho > 0 
\end{align*}
From the answer being positive, we can conclude that the corner solution will not occur. The equation shows that a decrease in $\delta$ reduces the equilibrium growth rate of output.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\partof{b}
While setting $\delta = \phi$ will eliminate distortion, it also makes the present value of invention profit zero. So there is no incentive for inventors to invest on producing new ideas. Since the long run growth in the economy is deriving by R\&D,
removing the incentives of the innovaters for R\&D will imply to no long run growth,
which is not socially optimal.
